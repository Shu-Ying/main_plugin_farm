# 网页头像栏与数据目录

## 头像栏

正式渲染器读取 `metadata.json` 的 `panel` 配置。头像、头像框、昵称、
经验条、等级、农场币和点券使用原始 `WebGLPersionInfo` prefab 的矩形、
锚点与文字对齐方式，不再使用旧版 `userInfo.png` 的位置。

来源为已下载公开资源包 `mainscene_053483f584f07436ac0569e2f4f7ed01`。
提取脚本只读取资源，不执行游戏脚本。原始包哈希及六张新增素材的哈希
记录在 `src/farm_render/source_assets/manifest.json`。完整头像框先于文字、
后于头像合成；Gold 的裁切透明边距按资源中的 textureRectOffset 恢复。

坐标以左上角为起点。Unity RectTransform 的锚点、pivot 和父矩形计算出
各元素矩形。渲染器采用宽 1920 的参考画布，输出坐标和尺寸乘以
`输出宽度 / 1920`；1280 像素网页截图按 2/3 对照。1920 是本渲染器的
对照基准，没有把它报告为已经提取到的网页 CanvasScaler 参数。

原始头像矩形为 `[32.2744, 39.7618, 111.3870, 107.7072]`，
头像框为 `[3.0930, 8.8650, 169.7500, 169.5000]`。昵称在头像右侧，
经验条与等级在昵称下方，农场币和点券在第三行。文字按矩形尺寸适配，
经验条裁切填充图片，不通过拉伸改变纹理。

保留本项目的账户与经验规则。网页的 VIP、晶钻、星钻及购买按钮没有
对应业务，不添加假余额或操作入口。渲染时暂时收起底板上原图纵坐标
168 到 208 的空栏区域，将原始下边框上移拼接。头像和现有文字的位置、
字号保持不变，面板可见高度约缩短 19%；原始素材完整保留，便于以后恢复。

## 数据目录

默认路径为宿主 `DATA_PATH / farm_db`，新版数据库名为 `farm.sqlite3`。
日志文件名和 deployment 标识保持不变。不再自动移动 `farm_preview`
目录，也不再因两个目录同时存在而阻止启动。

同目录旧版 `farm.db` 按用户在首次使用指令时迁移。用户永久绑定首次请求
的 deployment、机器人 ID 和平台，不跨身份重复导入；转换规则、失败处理
和不支持字段的保留方式见 [旧数据迁移](05-migration.md)。

原有显式 `farm_preview_data_dir` 配置继续生效。仅从选定目录读取旧版
`farm.db`；不会搜索其他目录。未发布预览版的 `farm-preview.sqlite3`
不自动改名或导入，预览数据由开发者手动处理。

本轮只修改开发源并进行隔离测试；没有移动正在使用的宿主数据或重启机器人。
