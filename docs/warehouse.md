# 仓库界面（方案C）

真寻命令「我的作物 [页码]」「我的种子 [页码]」分别查询当前用户库存。
省略页码为第1页，每页最多12种；只显示数量大于0的条目。
「我的农场 my-plant」「我的农场 my-seed」保留为对应入口。
「我的农场币」「我的点券」的原文字查询行为不变。

- 作物分为「可出售」「已锁定」，每组按稳定本地作物编号排序。
  编号跨页不变；可出售汇总排除已锁定项，单项价值为数量乘当前目录售价。
- 种子分为「单季种子」「多季种子」，显示粒数、首熟时间、最多收获季数。
  空地统计只计空地，枯萎地块需先铲除。
- 页首汇总整份库存，页内只展示当前12种；分组标题中的种数也是整组总数。
- 空仓库提供收获或种子商店提示；无字体时按相同分类与分页返回文字。
- 原库存编号在目录中缺失时保留项目，明确标注信息缺失，不按名称猜测。
  无法确定的售价不计入已知价值，汇总标明不含目录缺失项。
- 显示名称过长时省略，完整作物编号始终可用于文字操作。
- 使用现有木质面板和图标，默认JPEG压缩，复用有界异步渲染队列。
  查询只读取一次一致快照，不修改库存、土地、锁定状态或资产。

操作仍使用原有指令：出售作物、作物加锁、作物解锁、播种；支持名称和
`#编号`。不增加出售种子或种子锁定机制，不修改已有经济结算规则。
