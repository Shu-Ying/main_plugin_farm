# 当前经验规则

当前正式实现有四种经验来源：

| 来源 | 结算规则 |
| --- | --- |
| 成功播种 | 每成功播种 1 块地获得 2 经验；一次播种 3 块地获得 6 经验 |
| 收获成熟作物 | 每块地每季按播种时冻结的作物经验与该地块经验加成结算，然后累加 |
| 铲除枯萎作物 | 每实际清理 1 块枯萎地块获得 2 经验 |
| 除虫 | 每实际清除 1 只虫获得 1 经验；跨地块累加 |

收获单地块经验为 `基础经验 × (100 + 地块经验加成百分比) // 100`。
多季作物每季收获都会结算；虫害减产不减少收获经验。
购买、出售、查看农场或商店均不增加经验。
开通农场初始经验为 0。未实现的签到等玩法不属于当前经验来源。

播种、铲除和除虫奖励与对应地块更新及流水在同一数据库事务中提交。
失败不奖励，同一消息重试不重复奖励；已有历史操作不补发。
没有枯萎作物或虫子时不奖励。成熟后除虫仍按清除数量奖励，
但不会恢复已确定的本季虫害减产。铲除仍仅支持枯萎作物。

等级 k 的累计经验门槛为 `200 × k × (k + 1) // 2`。
经验条显示本级已获经验与本级所需经验：
`累计经验 - 当前等级门槛` / `200 × (k + 1)`。
例如累计经验 599、等级 1 时显示 399/400。
