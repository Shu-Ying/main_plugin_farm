# Constraints and invariants

源码使用 Python，4 空格、80 字符行长，明确说明数据模型字段。
保留 GPLv3 许可与源归属。共享核心内部相对导入。
运行数据和测试临时数据库不入 Git。新实现只使用必要依赖，
优先标准库 SQLite、异步线程执行和 unittest，不为框架引入依赖。
新数据库 schema 与旧库区分，未知或更高 schema 明确拒绝。
同一基础交易的存储和应用紧密耦合，使用单个 change，不拆分子任务。
