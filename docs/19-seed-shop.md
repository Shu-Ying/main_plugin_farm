# 文字指令种子商店

采用用户选定的方案二：木质价目板、单列六种。发送 `种子商店` 或
`种子商店 2` 返回 1024×1536 PNG；标题、余额、商品信息、购买示例和
页码都由程序绘制。原始作物 icon 复用包内资源；缺图显示“暂无图”。

显示农场等级、农场币和点券，商品显示稳定本地编号、名称、实际单价、
币种、购买等级、首熟时长、可收获季数和每季基础产量。
首熟时长和产量是目录基础值，虫害等实际种植结算仍由核心处理。
等级不足时突出“需 Lv.…”。未开通用户可浏览，购买仍需先开通农场。

只展示 buyable 作物，按本地编号排序，每页六种。最后一页不补假商品，
越界页码返回中文提示，页数按实际目录计算。字体不可用时返回同样分页的
文字列表。图片通过既有有限任务队列绘制，不在事件循环里执行 Pillow。
相同待处理请求合并，关闭时等待任务排空。

购买入口保持核心事务和消息去重不变：

- `购买种子 #1 5`
- `购买种子 胡萝卜 5`
- 名称有空格时使用引号；重名作物须用编号。

木牌空白底图为内置图像生成工具生成，非 QQ 农场原始资源。源文件
`src/farm_render/source_assets/webgl/shop-board.png`，由素材导出脚本加入
assets.zip，并在 metadata.json 保存 SHA-256。底图不含商品、价格和文字。
生成提示要点：1024×1536，QQ 农场风格暖色手绘木牌、橙色标题、米色纸面、
单列六个空白商品条、底部文字指令区；禁止生成文字、数字和商品图。

执行 `scripts/preview_shop.py --output <目录>` 可复现首页、第二页、末页与
未开通预览。预览余额为演示值，商品使用实际目录。此改动不部署、不重启。
