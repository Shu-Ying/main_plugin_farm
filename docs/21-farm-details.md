# 农场详述图片

`农场详述 [页码]` 返回上方全景与下方地块明细表，每页最多 10 块地。
`我的农场 detail [页码]` 是兼容入口。其他资产、种子和作物查询继续返回
原有文字仓库信息，不与新详述混用。

全景标注所有已解锁地块编号，黄色标出本页，表格沿用同一编号。
表格列为地块/作物、生长阶段、收获季数、预计/可收数量、成熟时间。
没有可靠的阶段名称元数据，因此生长阶段显示阶段序号，避免把发芽或
开花等名称猜错；与第几季/总共几季分别展示。时间采用北京时间。

生长中产量按当前虫数估算；预计成熟时间沿用核心虫害投影，包含后续
已确定的生虫事件。成熟后产量与收获一致：先计算土地加成向下取整，
再乘 `(100 - 成熟时虫数 × 5) // 100`。成熟后除虫不恢复被冻结的减产。
当前虫数、生长减速或成熟减产以小字列在对应行下方。

不显示被偷明细。当前领域模型尚无偷菜扣减字段或交易，故未伪造或
预扣偷菜损失。未来实现偷菜时，需同步接入实际收获结算与详述可收数量。

每次请求只读取一次账户快照，全景和明细使用同一快照与绘制时间，
不写入数据库。异步队列与农场/商店共享并发上限、去重和关闭排空。
字体不可用时返回同一数据口径的分页文字。输出遵循配置的图片格式，
AUTO 使用 JPEG。无效页码返回中文提示，未开通时返回开通提示。

运行 `scripts/preview_details.py --output <目录>` 可生成离线示例，
包括生长、成熟、虫害、成熟后除虫、空地、枯萎及两页地块。
示例余额与状态为构造数据，不访问真实玩家数据库。
