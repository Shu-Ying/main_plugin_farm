# 真寻预览接入

发布目标：https://github.com/Shu-Ying/zhenxun_plugin_farm.git
原指令、独立预览数据目录、身份和事件幂等、启动/关闭及发图接入。
不接入真寻金币兑换；旧版 farm.db 首次使用时按用户迁移到 farm.sqlite3。
核心/渲染由主仓库白名单打包，
生成时修正为插件私有相对导入，本目录本身不是完整安装包。
使用 scripts/build_zhenxun.py 生成ZIP，详见 docs/11-zhenxun-preview.md。
本轮没有拉取、推送或操作真实机器人。

## 开垦与旧用户土地

发送“开垦 条件”查看下一块地的等级和农场币费用，“开垦”每次新增
1块普通空地。目前配置覆盖7～24号地，表外拒绝开垦且不扣币。
扣款、新增地块及流水在同一事务完成，重复消息不重复扣款。

有可靠旧库迁移记录，或首次成功注册记录证明初始3块的账号，首次
业务访问时一次性补3块，保留付费成果、作物及土地加成。新版初始6块
账号不额外发地。来源不明、编号/数量异常或补后超出当前30位置的账号
保留原状并提示管理员处理，不自动截断或折现。

## 图片质量

真寻网页插件配置新增“农场图片质量”，整数1～95，默认75。
它统一控制我的农场、地块编号、农场详述、种子商店、我的种子及
我的作物图片的编码质量，修改后下一次图片请求生效。值越高通常
越清晰、文件越大；不会改变默认图片尺寸，PNG无损格式不受影响。
无效配置明确提示错误，不会自动截断或转换为合法值。

只有“我的农场 高清”接受高清，宽1536，质量取配置值与85的较大值。
其他命令不接受高清。仓库继续支持“我的种子 2 文字”和
“我的作物 2 文字”等分页文字查询。
